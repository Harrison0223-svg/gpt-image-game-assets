# Example records

This folder keeps the prompts, timing data and review records behind the demos described in `docs/`.

The image and GIF files these records reference are being migrated into this repository. Until that migration lands, they are available in the original project repository, [Harrison0223-svg/gpt-image-2d-assets](https://github.com/Harrison0223-svg/gpt-image-2d-assets), under:

- `examples/fox-motion/` — sprite sheets, cut frames and the preview GIF
- `examples/inventory/` — the inventory icon sheet and individual icons
- `examples/motion-validation-20260922/` — run/jump preview GIFs and the wave-hold sheet
- `docs/images/` — the illustrations used by the demo write-ups
