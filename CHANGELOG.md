# Changelog

All notable changes to this project are documented here.

## [0.1.0] - 2026-10-21

### Added

- First standalone release. The `gpt-image-2d-assets` Codex skill, its Python tools and their tests, the docs and the example records were extracted from the author's earlier fork into this dedicated repository for independent maintenance.
- GitHub Actions CI (Python 3.11 / 3.12) running both test files on push and pull request.
- `CONTRIBUTING.md`, `CREDITS.md` and this changelog.

### Notes

- The skill, tools, 24 game-art recipes and demos themselves were originally developed in September 2026; see `CREDITS.md` for provenance.
- Demo images and GIFs are still being migrated into this repository; until then they remain available in the original repository (see the "Demo media" section of the README).
